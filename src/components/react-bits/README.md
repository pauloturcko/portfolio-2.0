# React Bits Components

This directory is intended for UI components from [React Bits](https://reactbits.dev/).

Since React Bits doesn't have a single standard npm package that installs all components like Shadcn does, you should:
1. Find the component you want on the React Bits website.
2. Copy the source code for the component.
3. Paste it into a new file in this directory (e.g., `TextAnimation.tsx`).
4. Install any specific dependencies listed for that component (e.g., `framer-motion`).
